# Icônes de la page « Mes outils »

Les fichiers SVG sont servis localement, sans bibliothèque ni service externe à l’exécution. Leurs couleurs ont été adaptées au brun café du livre ; les noms des applications restent affichés en texte. Ces marques servent uniquement à identifier les outils utilisés, sans affiliation ni soutien implicite.

## Sources

- Figma, Canva, WordPress, Shopify, Instagram, TikTok, Godot, Maya, YouTube, ChatGPT (symbole OpenAI), Miro, Elementor et Astra : [Simple Icons 14.0.0](https://github.com/simple-icons/simple-icons/tree/14.0.0/icons), projet distribué sous [CC0](https://github.com/simple-icons/simple-icons/blob/14.0.0/LICENSE.md). Les droits propres aux marques restent applicables ; voir [l’avertissement du projet](https://github.com/simple-icons/simple-icons/blob/14.0.0/DISCLAIMER.md). Chaque SVG contient son URL source.
- WooCommerce : [Simple Icons 16.0.0, Woo](https://github.com/simple-icons/simple-icons/blob/16.0.0/icons/woo.svg).
- Godot : logo de Godot Engine, proposé par le [kit de presse officiel](https://godotengine.org/press/) sous [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Adaptation : couleur monochrome brun café.
- VS Code : [Devicon 2.16.0](https://github.com/devicons/devicon/blob/v2.16.0/icons/vscode/vscode-plain.svg), licence MIT ci-dessous. Adaptation : couleur brun café.
- CapCut : pictogramme déjà présent dans la version précédente du portfolio, repris en SVG et recoloré.
- Contact Form 7 : pictogramme éditorial de formulaire dessiné pour le portfolio ; il ne s’agit pas du logo officiel de l’extension.
